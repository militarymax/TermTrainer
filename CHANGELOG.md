## [1.0.0] — 2024-12-01

### Добавлено
- CLI-приложение на Go (single file, stdlib only)
- 10 факультетов, 160 заданий (.ex файлы):
  - 🏰 Основы Магии Терминала (`cli-basics`)
  - ⚗️ Алхимия Текста (`text-fu`)
  - 📜 Ритуальные Заклинания (`scripting`)
  - ⏳ Темпоральная Магия (`git`)
  - 🔎 Дешифровка Свитков (`jq-yq`)
  - 🌐 Магическая Связь (`netdebug`)
  - 🧪 Магические Сосуды (`docker`)
  - 🔮 Призыв Существ (`kubectl`)
  - ⚙️ Автоматические Чудеса (`cicd`)
  - 🌍 Создание Миров (`terraform`)
- Парсер .ex файлов с поддержкой секций: META, SETUP, TASK, ASSIGNMENT, VALIDATION, HINTS
- Интерактивный терминал (bash -i) с подготовкой окружения через SETUP
- Валидация решений через VALIDATION скрипты
- Система прогресса с XP и званиями (Студент-маг → Архиканцлер)
- Подсказки Магического Шара (HINTS, по одной за нажатие)
- Постраничный просмотр длинных свитков
- Лор Плоского Мира Терри Пратчетта во всех заданиях
- Makefile: build, test, lint, cross-compile (darwin/arm64 + linux/amd64)
- MIT лицензия
