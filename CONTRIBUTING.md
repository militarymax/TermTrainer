# 🧙 Контрибуция в TermTrainer

Спасибо за интерес к Незримому Университету Терминала! Этот документ поможет тебе внести свой вклад.

## 🚀 Быстрый старт

```bash
git clone https://github.com/militarymax/TermTrainer.git
cd TermTrainer
make build
./termtrainer
```

## 📜 Добавление нового задания

1. Создай файл `tasks/<факультет>/levelXX/NNN_name.ex`
2. Следуй формату из `tasks/TEMPLATE.ex.example`
3. Обязательно заполни: `META` (с `Title`), `TASK`, `VALIDATION`, `HINTS`
4. Опционально добавь `SETUP` (подготовка окружения) и `ASSIGNMENT` (пошаговое задание)
5. Проверь, что задание загружается: запусти `./termtrainer` и найди его в каталоге

### Правила заданий

- **Нумерация**: трёхзначный номер, уникальный в пределах уровня (001, 002, ...)
- **Порядок**: theory → practice → boss → uberboss (автосортировка по Type)
- **Факультет** определяется из пути файла, не нужно указывать `# Track` в META
- **XP** вычисляется автоматически из Difficulty — не указывай `# XP`
- **SETUP** должен быть идемпотентным — пользователь может нажать [R] несколько раз
- **VALIDATION** должен проверять результат работы, а не процесс — используй `✓` и `✗`

### Стилистика лора

- Используй метафоры Плоского Мира: Башня = файловая система, свитки = файлы, заклинания = команды
- Упоминай персонажей: Ринсвинд, Архиканцлер Чудакулли, Декан, Библиотекарь (Уук!)
- Эмодзи приветствуются 🧙📜⚗️🐉👑
- Пиши на русском языке

## 🏗️ Разработка кода

### Требования

- Go 1.21+, только стандартная библиотека (никаких внешних зависимостей)
- Single-file архитектура (`main.go`)
- Bash для скриптов проверки

### Сборка и тестирование

```bash
make build          # собрать бинарник
make test           # запустить тесты
make lint           # проверить код (go vet)
```

### Принципы кода

- **Stdlib only** — никаких внешних зависимостей
- **Single file** — весь код в `main.go`
- **Простота** — читаемость важнее хитрости
- **Кроссплатформенность** — должно работать на macOS и Linux
